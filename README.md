# skills-introduction-to-github
Exercise: Introduction to GitHub

## Instructions

1. Fork this repository.
2. Create a new branch named `exercise`.
3. Add a new file named `README.md` to the `exercise` branch.
4. In the `README.md` file, write a short introduction about yourself.
5. Commit and push your changes to GitHub.
6. Create a pull request to merge your changes into the `master` branch.

## Requirements

- You must use the `exercise` branch to make your changes.
- Your `README.md` file must contain a short introduction about yourself.
- Your introduction must be at least 100 words long.
